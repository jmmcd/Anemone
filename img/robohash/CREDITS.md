# Vendored identikit artwork

The images under this directory are **not** original to Anemone. They are
third-party artwork redistributed here under the licences below, downscaled and
re-encoded (see `scripts/build-robohash-parts.py` for the exact import) but
otherwise unmodified. The accompanying `manifest.js` records, for every part,
the upstream filename it came from.

| Directory | Set | Artist | Licence |
|---|---|---|---|
| `set4/` | Robohash `set4` — "Cat Avatar Generator" | [David Revoy](https://www.peppercarrot.com/extras/html/2016_cat-generator/) | [CC-BY 4.0](https://creativecommons.org/licenses/by/4.0/) |

Packaged by [Robohash](https://github.com/e1ven/Robohash) (code MIT; artwork
under the licences above, which differ per set). Robohash asks that projects
using its images mention where they came from — Anemone does so in `About.md`,
which is shown in the app, and in each individual's genome panel.

If you import another set with the build script, add its row here: the sets
carry *different* licences (`set1`–`set3` CC-BY-3.0, `set4` CC-BY-4.0, `set5`
free for personal and commercial use, `set6` CC0), and CC-BY attribution is a
condition of redistribution, not a courtesy.
